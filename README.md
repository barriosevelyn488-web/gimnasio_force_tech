## Gimnasio Force Tech

Este repositorio contiene el esquema, procedimientos, funciones, consultas y configuraciones necesarias para la gestión de un sistema de base de datos de un gimnasio. El objetivo es proporcionar una solución robusta y escalable para administrar socios, entrenadores, planes de entrenamiento, sedes y reportes.

## Estructura del Repositorio

- **`ddl/`**: Contiene el esquema de la base de datos, incluyendo la creación de tablas y relaciones.
- **`dml/`**: Incluye scripts para insertar datos iniciales (seeds) en las tablas.
- **`bucles/`**: Procedimientos almacenados que implementan estructuras de control como loops, while, repeat, y manejo de transacciones.
- **`consultas-avanzadas/`**: Consultas SQL avanzadas como joins, subconsultas y estructuras condicionales.
- **`consultas_innecesarias/`**: Ejemplos de consultas ineficientes para análisis y optimización.
- **`creacion_de_usuarios/`**: Scripts para la creación de usuarios y asignación de permisos en la base de datos.
- **`eventos/`**: Configuración de triggers y eventos programados para automatización de tareas.
- **`funciones_por_usuarios/`**: Funciones definidas por el usuario para cálculos específicos y validaciones.
- **`partición_de_tablas/`**: Scripts para implementar particionamiento en tablas grandes.

## Requisitos

- **MySQL**: Versión 8.0 o superior.
- **Workbench**: Para ejecutar y probar los scripts SQL.
